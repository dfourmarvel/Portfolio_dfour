Bible Quiz

Snakes & Ladders reimagined as a Bible trivia game — 875 questions, every one written twice, in a board game people already know how to play.

HTML5CSS3Vanilla JS (ES6+)PlaywrightNo build step
play it ↗ github ↗

Overview

A Bible trivia game wrapped in a board everyone's already played. You answer an entry question and roll a 6 to get on the board; from there, landing on a ladder or a snake triggers a question. Get it right and you climb, get it wrong and you slide. First player to land exactly on 100 wins.

The goal

Bible knowledge is usually tested in formats that feel like an exam — a quiz sheet, a list of verses to memorise. The bet here is that the format is the problem, not the content. Snakes & Ladders needs no explaining, so the questions arrive while people are already playing rather than while they're being tested.

The question bank

The bank behind the game is the part that took the real work. It started from a 1,000-question source and ended at 875 unique questions — and getting there meant treating it like data cleaning, not copywriting:

  • 50 questions (451–500) were missing from the source entirely — the original document had a placeholder where the content should be, then resumed at 501.
  • 72 questions were exact duplicates of others elsewhere in the bank. 75 redundant slots were removed, keeping the lowest-numbered instance of each.
  • Two answers were wrong or malformed and were corrected against the question content — Q903 was missing its book name ("32:24-32" only, corrected to Genesis 32:24-32), and Q38 had a stray clarifying clause trimmed out.

Every surviving question is rendered twice — once as a true/false item and once as multiple choice — which is 1,750 playable items from 875 questions. The multiple-choice distractors are real Bible references pulled from elsewhere in the same bank, matched to the same book where possible and the same testament otherwise. None of them are invented verses, which matters: a plausible-looking fake reference in a Bible game teaches the wrong thing. Each question carries an explanation and cross-reference verses.

How it's built

Vanilla HTML, CSS and JavaScript with no framework and no build step — you can open index.html and play. Game state, dice, questions, audio and storage all live in one script. Playwright drives the automated tests.

  • Optional AI players so the board still works with one person in the room.
  • Read-aloud support and background music with sound effects.
  • A skeleton shimmer loader for the board grid, and a layout that holds from phone to desktop.

what I learned

I expected the game to be the hard part. It wasn't — it was the 875 questions. Finding that 50 were simply missing from the source, that 72 were quiet duplicates, that an answer was wrong — none of that is glamorous work, and all of it happened before a single line of game logic mattered.

What stuck with me is how good it felt to refuse the shortcut. I could have generated plausible-looking wrong answers in an afternoon. Pulling every distractor from real verses in the same bank took far longer and nobody playing will ever notice. But I'd know, and a Bible game that teaches a fake verse is worse than no game at all.
