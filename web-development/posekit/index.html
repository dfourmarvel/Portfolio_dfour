posekit

Exercise animation where range of motion, tempo and load are parameters. A squat to 60% depth is the same movement travelling less far, not a different drawing.

TypeScriptSVGReact (optional)npmAGPL-3.0
live demo ↗ github ↗ npm ↗

Overview

I needed exercise demos for RoutineRx. Pre-rendered animation libraries have far more exercises, but every frame is fixed when it is drawn, so none of them can show a shallower squat or a slower tempo. posekit trades coverage for that control: the pose is solved from joint angles at runtime.

  • Coverage: 36 movement patterns, with an optional catalogue of 178 exercises built on them.
  • Adjustable: range of motion changes continuously; tempo, load and grip are settings.
  • Size: about 22 KB gzipped, against 14–90 MB for pre-rendered sets. That is the difference between working on a slow connection and not.
  • No third-party art: adding an exercise means writing keyframes, not commissioning an artist.
