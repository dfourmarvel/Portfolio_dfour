Afahyɛ

A Ghana-only marketplace for event vendors. Clients browse by category and region, send a structured brief, and receive quotes in a thread.

Pre-launch: the vendor listings are demo data, not real businesses, and it cannot take payments yet.

Overview

Afahyɛ is Twi for "festival". It covers the vendors a Ghanaian event needs: caterers, decorators, photographers, bands, venues, makeup artists, planners and small chops. A client finds vendors by category and region, sends one structured brief, and each vendor answers with a quote in its own thread.

How it is built

  • Data: Supabase Postgres, auth and storage, with row-level security on everything.
  • Server: Next.js server actions, each one validated with Zod.
  • Tests: Vitest for units and Playwright for end-to-end runs.
  • No AI: a vendor directory does not need a model, so the one the starter template shipped with was removed.
