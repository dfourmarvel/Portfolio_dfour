RoutineRx

A fitness tracker where the plan comes first. You set a weekly routine once, and each day opens on a check-off list instead of a blank logbook.

Overview

RoutineRx tracks cardio, bodyweight workouts and body weight. There is no gym or weights tracking, by design. The weekly routine decides what shows up each day, so logging a session is a tick rather than a form.

What it does

  • Daily check-off: the day's planned routine, ready to mark done.
  • Calories: food search across your own custom foods, a built-in table of common Ghanaian foods, and Open Food Facts, because global food databases miss most Ghanaian dishes. The daily target is calculated from your stats (Mifflin-St Jeor) and can be overridden.
  • Accounts: email or Google sign-in, with row-level security on every table so each person only ever reads their own data.
  • Installable: it is a progressive web app, so it can sit on a phone's home screen like a native app.
