Overview

A ground-up rebuild of my portfolio. Version 1 worked, but it was visually dull, read as AI-generated, had an empty projects page, and did not reflect the four areas I actually work in. v2 replaced all of it: new architecture, new design, new content model, real projects.

The goal

One test, written into the spec before any code: a stranger should leave the homepage able to say "medical student, serious about cybersecurity, builds websites and designs posters — and the site itself proves he can build." That last clause is the whole reason this is a hand-built site rather than a template. A portfolio claiming someone can build is evidence, not a claim.

The design

Three animated homepage directions were built as real, running pages and reviewed in the browser rather than as static mockups. The winner — "Vital Terminal" — is a fusion of a phosphor-green terminal and a hospital vitals monitor: the ECG strip in the hero, the heartbeat in the nav, the typing prompt. Medicine and cybersecurity in one visual language, which is the actual thesis of the site.

  • Dark only. No light mode and no toggle — the dark theme is the designed theme, not a default.
  • Per-domain accents — medicine is rose, cybersecurity green, web-dev cyan, design amber. This page is cyan because it's a web-dev page; the whole system is one CSS variable.
  • Hand-built details — custom hover states, intentional asymmetry, and a terminal that types itself out.

How it's built

Vanilla HTML, CSS and JavaScript. GSAP with ScrollTrigger is the single sanctioned dependency, loaded from a CDN — everything else is dependency-free, and there is no build step at all. The nav and footer are deliberately duplicated across every page: the honest cost of having no build, paid knowingly.

The rule the animation system is built around: content must never be stuck invisible. Every hidden-until-animated style is gated behind a class that JavaScript only adds after confirming GSAP will actually run. If the CDN fails, the script dies, or a browser refuses — the page is still fully readable. prefers-reduced-motion collapses every decorative animation, and that is treated as non-negotiable rather than a nice-to-have.

what I learned

There is something uniquely exposing about building the thing that is supposed to prove you can build things. Every shortcut I might have taken elsewhere would be sitting right there in the evidence. So the ECG in the hero had to be hand-made, the terminal had to actually type, and the reduced-motion path had to genuinely work rather than merely exist.

The lesson that stuck was about the boring parts. The animation contract — content never stranded invisible if the CDN dies — is the piece I am quietest about and proudest of. Nobody will ever notice it working. That turns out to be the point: the difference between a site that looks impressive and one that is actually built is entirely made of things nobody notices.
