# Portfolio_dfour

Daniel Dela Dzikunu's personal portfolio site (medicine + cybersecurity focus). Vanilla HTML5/CSS3/JS, no framework, no build step, no package.json.

## Structure
- `index.html`, `script.js`, `style.css` — main site shell
- `pages/` — additional pages (About, Projects, Skills, Blog, Contact)
- `projects.js` — project data/listing logic
- `assets/` — images/media

## Commands
- No build/test tooling — open `index.html` directly in a browser, or use the `run` skill.

## Conventions
- No external dependencies by design — keep it dependency-free.
- Light/dark mode with persistence already implemented — match existing patterns for any new UI.
- Content should reflect Daniel's actual work (e.g. new cybersecurity labs, medical/dev projects) — check `cybersecurity-labs` and other project repos when updating the Projects section.
