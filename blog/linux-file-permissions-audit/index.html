Where it started: auditing Linux file permissions

May 22, 2026 linux google cybersecurity certificate lab

I am excited to share a milestone in my cybersecurity journey! While this isn't my first hands-on lab, it is the very first one I have formally documented as part of my progress toward the Google Cybersecurity Professional Certificate.

In this lab, I stepped into the role of a security analyst tasked with auditing and securing a research team's Linux development environment to align it with strict organizational data protection policies.

The Mission: Eliminating Authorization Vulnerabilities

Operating within a Bash terminal, I used commands like ls -al to uncover hidden files and analyze the 10-character permission strings of the environment's directories and assets. I quickly identified several over-permissive write access issues and hidden file exposures that violated our compliance standards.

The Fix: Applying Least Privilege

To bring the environment to a secure state, I systematically modified file modes using the chmod command to enforce the Principle of Least Privilege:

Public Write Access Revoked: Discovered that project_k.txt allowed write permissions for anyone (-rw-rw-rw-). I executed chmod o-w project_k.txt to strip public write authorization.

Securing Hidden Assets: Located a hidden file, .project_x.txt, with improper permissions. Through targeted commands like chmod g+r,g-w, I transitioned it to a secure, read-only state for both the user and the group (-r--r-----).

Directory Isolation: Inspected the drafts directory, which initially allowed execute-only access to the group (drwx--x---). By running chmod g-x drafts, I completely restricted entry to the owner alone (drwx------).

The Takeaway

Linux file permissions are a fundamental pillar of access control. Successfully auditing these permissions and resolving vulnerabilities silently and effectively via the CLI was an incredibly rewarding experience. Documenting this process has reinforced how critical the principle of least privilege is to keeping organizational data safe.
